# MC635708-Ding Huiyuan — Data Science Portfolio

Portfolio repository for **CISC7204 Practice 09: Build Your Data Science Portfolio**.

The website introduces Ding Huiyuan, lists skills demonstrated in the project, and showcases an ongoing analysis of Macao visitor arrivals and hotel occupancy in 2015–2025. It includes three real visualizations, findings, limitations, attribution, and a link to the reproducible project repository.

- [Project repository](https://github.com/DingHuiyuan-MC635708/data-science-project)
- [Website source](index.md)

## GitHub Pages deployment

In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, **main**, and **/ (root)**, then save. The root `index.md` is the entry file and `_config.yml` selects the Cayman theme.

Use the live URL reported in Pages settings after deployment. Verify the website, images, and project links before submitting it to the HOME/SUPPORT Class M forum.

## Update

Edit `index.md`, update the image files in `assets/` if the analysis changes, and commit with a descriptive message. Obtain a classmate's actual feedback on the purpose, main finding, and limitation, then commit one concrete improvement based on that feedback. Do not claim feedback has occurred until it has.
